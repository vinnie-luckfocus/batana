| 项 | 规格要求 | 数量 | 估价 | 说明 |

**候选样品评估（2026-09-18）——HBVCAM-W2237-2 V11：可采购**（选 72°/f=3.6mm 款）：

- ✅ 满足核心项：OV9281 黑白全局快门、UVC 免驱、Type-C/USB3、基线 120mm 固定（恰在我们推荐区间上限，精度最好）
- ✅ YUY2 无压缩可用：mono 传感器色度通道为空，YUY2 亮度无损；低分辨率下带宽 < 2Gbps，MONO8 缺失无实质影响
- ⚠️ 取舍：120fps 仅 1280×400 合并（640×400/眼）；中间档 800×600/眼@100fps；全分辨率 1280×720/眼 只有 60fps
- 精度核算（δz = z²·δd/(b·f_px)，b=120mm、δd=0.15px）：640×400@120 → ~14–18mm@2.5m（临界）、~9–11mm@2m（✓ 达 P3 出口 15mm@2m）；800×600@100 → ~11–14mm@2.5m ✓；1280×720@60 → ~7–9mm@2.5m ✓✓
- 下单前向客服确认：① 640×400 模式是 2×2 binning（保 FOV）还是中心裁剪（FOV 减半则覆盖不足）；② 是否可定制 2560×800@120 固件
- 定位：路线 A 的快速验证样品；120fps 全分辨率上限仍由路线 B（VEYE 1280×1080@120 RAW）兜底，双轨策略不受影响

## 3. 软件与账号平台搭建（零采购）

### 3.1 macOS 开发机（V1 模型转换 + V3 构建 + core 调试主机）

- Flutter stable + `flutter doctor` 全绿；Xcode（免费 Personal Team 即可真机调试）；Android Studio（SDK 34+、NDK）
- Python 3.11 venv：`rknn-toolkit2`（TFLite→RKNN 转换在主机侧完成；**macOS arm64 wheel 支持待验证，属风险 R3**）
- CMake、Git（已有 gh 认证）
- **USB 双目模组可直插 MacBook**（Type-C，UVC 免驱）作 batana-core 算法调试 + 移动数据采集站（标定工具、3D 重建、M1.5 数据集录像落盘）；注意 macOS UVC 对 MONO8 枚举不稳定，先探测格式，兜底 YUY2 取 Y 通道；**性能验收（帧配对/PTS/长时掉帧）必须在 RK3588/泰山派目标平台做**

### 3.2 ROCK 5B+ 首次点亮（V1）

1. 下载 Joshua-Riek `ubuntu-rockchip` 24.04 镜像（已支持 5B+，含 RKNPU 0.9.6 + librknnrt）
2. balenaEtcher 烧录 microSD → 上电（先接散热器与天线）
3. 串口（1500000 baud）或 SSH 登录 → 验证 `dmesg | grep rknpu`
4. 跑 NPU 基准脚本（M0 spike 代码，落 batana-pi `spikes/`）

### 3.3 Yocto 构建环境（V2，注意：macOS 不能原生构建）

- 需要 **Linux x86_64** 环境：Ubuntu 22.04/24.04，≥200GB 空闲磁盘、≥16GB RAM
- macOS 三选一（D0 定方案）：OrbStack Docker Ubuntu 容器（最轻，需验证 bitbake 兼容）/ UTM 虚拟机 / 云主机按量（~¥1–2/小时）
- 构建链：`meta-rockchip`（scarthgap）+ `meta-qt6`，先跑通 core-image 再集成 eglfs HelloWorld

### 3.4 账号

- 已有：GitHub（gh 已认证）
- 新增（免费）：Radxa 论坛（资料/答疑）、淘宝/京东采购账号
- 暂缓（P4 才需要）：Vercel / Neon / Cloudflare R2

## 6. 完备性自检

逐项核对结果：

- [x] V1 NPU 基准：板 + 散热 + 电源 + SD 卡 —— 齐
- [x] V2 Qt6 构建链：板 + 显示屏 + Linux 构建环境（3.3）—— 齐
- [x] V3 Flutter 240fps：手机（G，待确认）+ macOS 工具链 —— 齐
- [x] V4 双目采集：路线 A + B 并行 + 万用表/烙铁 —— 齐
- [x] 3D 精度定案：标定板 + 球棒 + Tee + 三脚架 —— 齐
- [x] 类别覆盖：供电 ✓ / 存储 ✓ / 散热 ✓ / 显示 ✓ / 调试 ✓ / 线缆 ✓ / 结构支架 ✓ / 测试道具 ✓ / **拍摄环境（补光、照度计、防护挡板）✓**
- [x] 自查中发现并已补充的易漏项：**IPEX 天线**（不接则蓝牙不可用）、**散热器**（5W 功耗墙）、**1.5Mbps 串口线**（普通 CH340 不稳）、**标定板**（A0 规格，精度比对基准）、**补光灯**（笼灯差需求 15–50 倍）、**排线首件核对工具**（万用表）

结论：M0 四个验证项的物料与软件环境均已覆盖，无遗漏类别。
