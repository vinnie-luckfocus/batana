# Batana 生态 UI/UX 规范

> 版本：v1.0（2026-09-23）· 状态：生效中 · 维护方：batana（司令塔）
> 适用范围：**batana-tool（Tauri/macOS）· batana-app（Flutter）· batana-gui（Qt6/QML 嵌入式）· batana-web（Next.js）**
> 本文件是 Batana 生态所有用户界面的**唯一权威规范**。新界面开发、旧界面整改、设计评审均以本文件为准；修订需更新版本号与日期。

## 1. 设计原则

1. **原生优先**：优先使用平台原生控件与系统材质，自定义绘制只用于原生给不了的部件。不发明"自创风格"。
2. **跟随系统**：浅色/深色外观、强调色、字体缩放一律跟随操作系统，不做应用内主题切换器（macOS/iOS/Android/Windows 均如此）。
3. **一套令牌**：所有平台共享同一套设计令牌（本文件第 3 节），平台差异只允许出现在落地映射（第 7 节），不允许出现在取值上。
4. **信息克制**：一屏一个主任务；正常状态不用 emoji、不用 ASCII 装饰、不用全大写标题；状态指示仅 ✅❌⚠️ 且谨慎使用。
5. **可验证**：每次 UI 改动必须截图验收（浅色/深色 × 关键尺寸），截图随 PR/提交留档。

## 2. 设计语言：macOS 原生（Liquid Glass 观感）

以 Apple HIG 与 macOS 26 的 Liquid Glass 观感为基准：

- **材质分层**：窗口背景用系统毛玻璃（vibrancy / sidebar material）；卡片用**半透明面**让模糊透出来，禁止用不透明色盖住毛玻璃。
- **表面质感**：连续圆角、0.5px 发丝级半透明描边、统一方向的软阴影（光源恒在正上方）。
- **内容优先**：chrome（边框、工具栏）退后，内容上前；分割用留白与发丝线，不用粗边框。

## 3. 设计令牌（Design Tokens）

### 3.1 语义色

取值 = macOS 系统色。实现时应优先调用系统色 API（`NSColor` / `Color(uiColor:)` / CSS `light-dark()` + 系统变量），下表为兜底基准值。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `accent` | `#007AFF` | `#0A84FF` | 主操作、选中态、链接、聚焦环 |
| `green` | `#28CD41` | `#30D158` | 就绪 / 成功 |
| `red` | `#FF453A` 深 / `#FF3B30` 浅 | 同左 | 异常 / 破坏操作 / 录制提示 |
| `orange` | `#FF9500` | `#FF9F0A` | 警告 / 待复核 |
| `yellow` | `#FFCC00` | `#FFD60A` | 提示 |
| `fg` | `#1D1D1F` | `#F5F5F7` | 主文本 |
| `fg_dim` | `#86868B` | `#98989D` | 次要文本 / 占位 |
| 卡片面 | `rgba(255,255,255,.72)` | `rgba(30,30,32,.64)` | 半透明卡片底（透出毛玻璃） |
| 发丝描边 | `rgba(0,0,0,.08)` | `rgba(255,255,255,.12)` | 卡片/分隔描边，0.5–1px |

### 3.2 字体

- 正文/标题：系统字体（SF Pro / PingFang SC；Flutter 用 `fontFamily: system`；Web 用 `-apple-system` 栈），**不内置第三方字体**。
- 数值读数（遥测、计数、时间码）：等宽数字——macOS 用 SF Mono/Menlo 或系统字体的等宽数字特性（`font-variant-numeric: tabular-nums`）。
- 字号阶梯（pt/px 等价）：11 辅助 · 12 次要 · 13 正文 · 15 强调正文 · 20 区块标题 · 28 页面主标题。行高 ≈ 1.35–1.5。

### 3.3 间距与栅格

- **8pt 网格**：所有内外边距取 4 的倍数，优先 8 的倍数（4/8/12/16/20/24/32）。
- 页面边距：16 左右、12 上下；卡片内边距：12–16；卡片间距：12；表单行距：10，标签-控件间距：16。
- 窗口最小尺寸：桌面工具类 **1100×680**；内容不足时控件弹性拉伸而非留白漂移。

### 3.4 圆角 / 描边 / 阴影

- 圆角：小组件 6，按钮/输入框 8，卡片 12–14，模态 14。
- 描边：0.5–1px 半透明（见 3.1），禁用纯色实线边框。
- 阴影：单一方向（正下方 dy=6，blur=28，不透明度 ≤12%），禁多方向/彩色阴影；滚动容器内组件不挂阴影（会被视口裁剪）。

### 3.5 动效

- 时长：微交互 120–200ms，面板/页面 240–320ms；缓动 `ease-out` 或系统弹簧。
- 状态反馈必须有动效（按钮按下缩放 0.98、状态 pill 变色过渡），但**禁止装饰性动效**（无意义的漂浮、循环闪烁）。
- 尊重系统「减弱动态效果」设置。

## 4. 组件规范

- **主按钮**：accent 实底白字，一屏至多 1 个；次要按钮：半透明灰底；破坏操作：红字/红底浅填充，需二次确认。
- **卡片**：半透明底 + 发丝描边 + 统一软阴影；卡片内不再嵌套卡片。
- **状态 pill**：语义色 12% 底 + 语义色文字，圆角全圆角；状态变化有过渡。
- **分段控件（ segmented ）**：用于互斥视图切换（如左目/右目/双目），不用下拉框。
- **下拉框**：只用于选择项 > 4 或动态枚举（如相机设备）；动态枚举必须支持刷新且保留当前选择。
- **表单**：标签右对齐、控件列弹性拉伸；设置类页面内容超高时用滚动区。
- **通知横幅**：顶部横幅呈现警告/异常，暖色半透明底，可自动消隐；错误文案必须包含解决方法。
- **空态**：用一句话说明「这里会有什么 + 怎么开始」，不放插画堆砌。

## 5. 文案与语音语气

- 全中文；动词开头的操作（「开始采集」而非「采集启动」）；不堆敬语。
- 语音提示短句化（「请就位」「挥棒」「已保存」），异常提示先说结论再说解法。
- 时间戳一律 ISO 8601 UTC 存储、本地时区展示。

## 6. 可访问性

- 文本对比度 ≥ 4.5:1（浅深色都要验）；语义状态不能只靠颜色传达（配图标或文案）。
- 全键盘可达：主操作有快捷键（空格=开始/结束等），焦点环用 accent。
- 跟随系统深色模式实时切换，切换时不丢状态、不闪屏。

## 7. 平台落地映射

| 令牌/能力 | Tauri（Web/CSS） | Flutter | Qt6/QML | Web（Tailwind） |
|---|---|---|---|---|
| 语义色 | CSS 变量 + `light-dark()` | `ColorScheme` 自定义扩展 | QPalette + 语义表 | CSS 变量 |
| 毛玻璃 | macOS `window-vibrancy`（NSVisualEffectView） | `BackdropFilter`（限 macOS 桌面） | NSVisualEffectView 桥接 | `backdrop-filter: blur()` |
| 系统字体 | `-apple-system` | 默认即系统字体 | 默认即系统字体 | `-apple-system` 栈 |
| 等宽数字 | `tabular-nums` / SF Mono | `FontFeature.tabularFigures` | SF Mono/Menlo | `tabular-nums` |
| 阴影令牌 | `box-shadow: 0 6px 28px rgba(0,0,0,.12)` | 同值 BoxShadow | 同值 QGraphicsDropShadowEffect | 同 CSS |

各仓可在本规范之上补充**仓级细则**（如组件库选型），但令牌取值不得覆写。

## 8. 验收清单（每次 UI 改动必过）

1. 浅色 + 深色截图各一套，关键窗口尺寸（最小 1100×680 + 常用尺寸）各一套。
2. 运行时切换系统外观：所有自绘组件颜色正确跟随，无残留旧主题色。
3. 窗口拉到最小尺寸：无截断、无重叠、无错位。
4. 对比度抽查：次要文本/描边在两种外观下可读。
5. 截图留档于仓库或 PR 描述中。
